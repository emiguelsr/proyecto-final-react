# Proyecto Final - React JS

Este proyecto es mi entrega final del curso React JS. Lo fui armando de a poco con React, Firebase y varias herramientas que me sirvieron para practicar un eCommerce bastante completo.

## Que hace la app

La idea principal es simple: mostrar productos, ver su detalle, agregarlos al carrito y dejar un panel para gestionar el catalogo. Tambien tiene login, registro, busqueda, paginacion y un diseño responsive para que se vea bien en celular y en escritorio.

## Lo que incluye

### Carrito
- Agregar productos con cantidad.
- Eliminar productos del carrito.
- Vaciar el carrito completo.
- Ver el total.

### Productos
- Lista de productos con busqueda en tiempo real.
- Pagina de detalle de cada producto.
- Paginador para ordenar mejor el catalogo.

### Gestion
- Crear productos.
- Editar productos.
- Eliminar productos con modal de confirmacion.
- Carga de imagenes para los productos.

### Usuario
- Registro.
- Inicio de sesion.
- Cierre de sesion.
- Rutas protegidas para secciones privadas.

### Diseño
- Uso de Bootstrap y React-Bootstrap.
- Iconos con React Icons.
- Metatags con React Helmet.
- Estilos con CSS Modules y styled-components.

## Tecnologias que use

- React
- React Router
- Context API
- Firebase Authentication
- Firebase Firestore
- Bootstrap
- React-Bootstrap
- React Icons
- React Helmet
- styled-components
